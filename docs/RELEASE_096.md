# Phosphoreya 0.9.6

Новое название — прежние записи. Приложение теперь называется **Phosphoreya**.

- Один инструмент масштаба: крутилка по умолчанию, ползунок или кнопки в настройках плагина «Кинетичный зум». Минимальный масштаб показывает всю карту.
- Развёрнутость редактора запоминается на этом устройстве. Прокрутка ограничена внутренней областью окна, действия остаются сверху.
- Таблицы Markdown редактируются прямо в обычном режиме. Кнопка таблицы создаёт новую; Tab перемещает между ячейками и добавляет строку в конце. Поддерживаются изображения, списки, цитаты, код и ссылки. Неизвестные расширения Markdown сохраняются исходным текстом.
- Папки остаются на месте при открытии заметки. Верхние панели больше не соприкасаются. Добавлена иконка вкладки браузера.
- Геометрия связей повторно используется при движении камеры. Кеш измерений текста рассчитан на карты с тысячами подписей.
- В подключении устройств явно разделены общий профиль рабочих плагинов и локальное оформление.

## Уже установлено приложение со старым названием?

Продолжайте открывать его: старый адрес `/Phosphorea/` тоже получает обновления.
Переустанавливать приложение или удалять данные браузера не нужно.
Новый адрес — [Phosphoreya](https://svyatoslavpodolskii.github.io/Phosphoreya/).
На том же браузере и профиле это та же локальная база. Другой браузер или профиль —
отдельное хранилище; используйте синхронизацию или резервную копию.

Ключи сопряжения и форматы резервных копий сохранены. Название уже установленного
ярлыка может обновляться по правилам браузера; старый ярлык продолжает работать.
