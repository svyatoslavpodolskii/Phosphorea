# Публикация

Основной репозиторий и адрес:

- https://github.com/svyatoslavpodolskii/Phosphorea
- https://svyatoslavpodolskii.github.io/Phosphorea/

Прежний Pages-сайт `Phosphora` отключён после сохранения резервной копии владельцем.
Публикуйте только основной репозиторий:

```sh
git push origin main
```

Форматы резервных копий, ключи настроек и пути SQLite/OPFS сохранены.
Данные между устройствами переносятся синхронизацией или полной резервной копией.

Исходники ролика хранятся в `film/` вместе с проектом. Готовый MP4 публикуется
в релизе; WAV, превью и прочие результаты рендера исключены через `.gitignore`.
Отдельный архив и отдельный пакет движка не выпускаются.

## Публикация новой версии

1. Обновите версию в `package.json` и `package-lock.json`.
2. Добавьте запись первой в `src/ui/releases.ts`. Номер должен совпадать с версией
   приложения. Описывайте изменения для пользователя: что теперь можно сделать
   и чем это поможет. Обычно достаточно трёх коротких пунктов.
3. Добавьте заметку `docs/RELEASE_XXX.md` и обновите ссылку в `docs/README.md`.
4. Выполните `npm run check`, `npm test`, `npm run build`.
5. Проверьте окна и историю: `npx playwright test --config tests/release.config.ts`.
   Проверьте настоящее обновление PWA: `npx playwright test --config tests/pwa.config.ts`.
6. Опубликуйте коммит в `main` и дождитесь успешного GitHub Pages.

Обновление никогда не должно перезагружать работающий редактор без выбора
пользователя. История показывается один раз после смены версии; отметка о прочтении
и откладывание обновления относятся к устройству и не синхронизируются с дневником.
