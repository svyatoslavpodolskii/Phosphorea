# Публикация

Основной репозиторий и адрес:

- https://github.com/svyatoslavpodolskii/Phosphorea
- https://svyatoslavpodolskii.github.io/Phosphorea/

`Phosphora` сохранён как совместимый прежний репозиторий: переименование GitHub
не перенаправляет старые GitHub Pages URL. Существующие установленные приложения
должны продолжать открываться по старому адресу. Не удаляйте этот Pages-сайт и
не заменяйте его принудительным перенаправлением без подготовки переноса данных.

`origin` указывает на Phosphorea, `legacy` — на Phosphora. Во время переходного
периода проверенную сборку можно публиковать в оба репозитория:

```sh
git push origin main
git push legacy main
```

Оба workflow собирают одно приложение с относительными путями. Форматы резервных
копий, ключи настроек, пути SQLite/OPFS и идентификаторы существующих баз при смене
имени не меняются. Данные на разных устройствах или в разных контейнерах браузера
переносятся полной резервной копией.

`film/` содержит только исходники, семплы с лицензиями и инструкции движка.
Тяжёлые рендеры исключены через `.gitignore`. Для отдельного архива движка:

```sh
python film/archive.py
```
