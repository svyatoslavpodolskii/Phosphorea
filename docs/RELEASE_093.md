# Phosphorea 0.9.3

Синхронизация больше не зависит от открытого окна устройств. Связанные устройства
обмениваются сохранёнными изменениями автоматически и соединяются после повторного
открытия приложения. Оба приложения должны быть открыты и доступны в сети.

Исправлены передача сохранённых координат и двусторонний обмен. Разные хранилища
не объединяются автоматически; на обоих устройствах можно выбрать входящие хранилища.
Состояние и настройки плагинов, пользовательские пакеты и типы заметок передаются
вместе с общим профилем. Оформление принимается только по желанию получателя.

Обновите приложение на обоих устройствах. Старую пару нужно один раз подтвердить
заново. Данные прежней версии остаются на месте; ранее слитые записи не удаляются.

Проверки: модульные тесты сохранности данных и причинных версий; сквозные тесты
на двух изолированных браузерных хранилищах, включая координаты, автоматические правки,
перезапуск, состояния плагинов, личную тему, QR, отмену и офлайн-конфликты.
