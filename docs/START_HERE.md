# Phosphorea: начать за минуту

**[Открыть приложение](https://svyatoslavpodolskii.github.io/Phosphorea/)** · [Исходники](https://github.com/svyatoslavpodolskii/Phosphorea)

Ничего скачивать с GitHub не нужно. Откройте ссылку на приложение в обычном
окне браузера, дождитесь загрузки карты и начинайте писать. Аккаунт не нужен.
После первой загрузки приложение можно открывать без интернета.

## Добавить значок приложения

Названия пунктов немного различаются в разных версиях браузеров. Если не
видите кнопку установки, обновите браузер или продолжайте работать во вкладке.

### Android — Chrome

1. Откройте ссылку на приложение в Chrome.
2. Нажмите меню **⋮ → Добавить на главный экран → Установить**. Иногда пункт
   сразу называется **Установить приложение**.
3. Подтвердите установку. Открывайте Phosphorea новым значком.

[Справка Chrome для Android](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid).

### Android — Firefox

1. Откройте приложение в Firefox.
2. В меню **⋮** выберите **Установить** или **Добавить на главный экран**.
3. Подтвердите добавление значка. Способ открытия зависит от версии Firefox и
   Android: это может быть отдельное окно или ярлык страницы.

[Справка Firefox для Android](https://support.mozilla.org/en-US/kb/use-web-apps-firefox-android).

### iPhone и iPad — Safari

1. Откройте приложение в Safari.
2. Нажмите **Поделиться → На экран «Домой»**.
3. Если есть переключатель **Открывать как веб-приложение**, включите его.
4. Нажмите **Добавить**. Открывайте карту значком с экрана «Домой».

[Справка Apple](https://support.apple.com/guide/iphone/iph42ab2f3a7/ios).

### Windows, macOS и Linux — Chrome

1. Откройте приложение в Chrome.
2. Нажмите значок установки справа в адресной строке. Если его нет, откройте
   **⋮ → Трансляция, сохранение и отправка → Установить страницу как приложение**.
3. Подтвердите. Ярлык появится среди приложений вашей системы.

[Справка Chrome для компьютеров](https://support.google.com/chrome/answer/9658361).

### Windows — Firefox

В актуальном Firefox для Windows нажмите кнопку веб-приложения в адресной
строке. Приложение откроется отдельным окном; его можно закрепить на панели
задач, а затем открывать через меню «Пуск». Если кнопки нет, обновите Firefox.
В Firefox на macOS и Linux такой установки пока нет: используйте вкладку,
Chrome или Safari на Mac.

[Справка Firefox для Windows](https://support.mozilla.org/en-US/kb/web-apps-firefox-windows).

### Mac — Safari

В Safari на macOS Sonoma 14 и новее откройте приложение и выберите
**Файл → Добавить в Dock**. Задайте имя Phosphorea и подтвердите.

[Справка Safari](https://support.apple.com/en-us/104996).

На Chromebook приложение можно установить через Chrome тем же способом,
что и на компьютере. Это веб-приложение: отдельные APK, EXE и покупка в магазине
для работы не нужны.

## Первая заметка и карта

1. **Создайте атом:** зажмите пустое место карты и отпустите палец. Напишите
   название и текст, нажмите **Готово**. На компьютере также работает долгое
   нажатие мышью.
2. **Откройте заметку:** нажмите на атом. В редакторе доступны форматирование,
   списки и задачи, тип заметки, оформление и отправка текста.
3. **Перемещайте карту:** ведите по пустому месту. Масштаб меняется щипком,
   колёсиком мыши или управлением зумом на экране.
4. **Переместите атом:** ненадолго зажмите его и потяните. Чтобы связать два
   атома, перетащите один на другой. Повторный перенос на уже связанный атом
   убирает эту связь.
5. **Выделите несколько:** зажмите пустое место и, не отпуская, обведите атомы.
   После выделения доступны общие действия и создание папки.
6. **Найдите запись:** нажмите лупу, введите слово из названия или текста и
   выберите результат. Поиск умеет показывать заметку на карте.
7. **Организуйте дела:** используйте «Сейчас», «Обычные», «Архив» и канбан.
   Архив сохраняет запись и её связи.

В меню карты находятся **Настройки и резервные копии**. Оформление и плагины
позволяют менять темы, поведение карты, жесты, зум, типы заметок и другие детали.

## Где мои записи и как их не потерять

Записи хранятся локально в этом браузере или установленном приложении.
Установка не включает синхронизацию с другим телефоном или компьютером.

**Сделайте полную копию:** меню карты → **Настройки и резервные копии →
Данные и копии → Создать резервную копию**. Сохраните файл в надёжное место.
Повторите для каждого хранилища, которое хотите перенести.

На другом устройстве или в другом браузере откройте те же настройки и выберите
**Восстановить из копии**. Восстановление заменяет текущее выбранное хранилище,
поэтому приложение предлагает сначала сохранить его копию.

Не очищайте данные сайта ради обновления. Работайте вне приватного режима.
Браузеры и установленные веб-приложения иногда используют разные локальные
хранилища: если после установки видите пустую карту, исходные записи могут
оставаться в прежнем браузере. Сделайте там копию и восстановите её в приложении.

Старый адрес `/Phosphora/` оставлен для совместимости с существующими ярлыками.
Основной адрес — `/Phosphorea/`. Перед сменой браузера или ярлыка сохраните копию.
