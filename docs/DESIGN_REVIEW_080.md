# Phosphora 0.8.0 — проверка интерфейса

Применены design-engineering и apple-design. Ориентир — спокойные материалы,
ясная иерархия, короткий отклик и управление одной рукой. Исходные снимки:
`artifacts/design-audit/before.html`, обновлённые: `artifacts/design-audit/after.html`.
Галереи создаются локально и не включаются в публикацию приложения.
Исходный проход: 102 снимка; обновлённый: 113 снимков.

| До | После | Почему |
| --- | --- | --- |
| Настройки сразу показывают копии, импорт, технические сведения и подсказки | Три направления: оформление, плагины, данные; диагностика свёрнута | Повседневные действия легко найти |
| У каждой строки плагина несколько очерченных кнопок | Монохромная иконка, переключатель, стрелка настроек | Меньше визуального шума, состояние видно сразу |
| Светящаяся обводка территории папки | Полупрозрачное мягкое пятно без контура | Папка организует карту, не перетягивает внимание |
| Зум только ползунком | На выбор ползунок или крутилка с делениями, клавиатурой и щелчками | Управление одним пальцем; выбор сохраняется плагином |
| Служебный текстовый символ сохранения | SVG-щит с галочкой, отдельные состояния сохранения и ошибки | Единая графика и понятный смысл |
| Одинаковые названия тем, происхождение не видно | Кисть у пользовательских тем, номера у совпадающих названий | Различимость без изменения импортированных данных |
| Всплывающие уведомления далеко от нижней панели, держатся долго | Ниже, обычные 1.8 с, отмена 3–3.2 с | Меньше перекрытий; отмена удаления остаётся в меню |

Звуковой отклик — отдельный встроенный плагин с громкостью. По прямой просьбе
пользователя включён по умолчанию; верхняя кнопка мгновенно отключает его и
запоминает выбор. Звук создаётся локально через Web Audio, запускается только
после действия пользователя; при загрузке и в фоне ничего не воспроизводится.
Короткие сигналы не требуют загрузки медиа и не подменяют видимый отклик.
В галерее есть WAV для прослушивания четырёх сигналов на штатной громкости.

Проверены все 16 встроенных тем: карта, редактор и выбор оформления. Отдельно
сняты мобильные и настольные меню, поиск, редактор и его панели, подтверждения,
папки, канбан, повторения, хранилища, плагины и резервные копии. Системные окна
выбора файлов и Android Share находятся вне снимков веб-интерфейса.

Проверки: `npm run check`, `npm test`, `npm run build`; браузерные сценарии
`design-audit`, `tactile-design`, `delete-regression`, `themes`, `native-backup`.
251 модульный тест прошёл. В Chromium прошли 13 целевых сценариев,
в Firefox — 5 сценариев удаления, крутилки, звука и настроек.
Полная копия проверяет восстановление заметок и настроек плагина, изоляцию
хранилищ и отказ от повреждённых данных. Схема SQLite не изменена.

Воспроизведение аудита после сборки:

```powershell
npx playwright test --config playwright.design.config.ts design-audit.spec.ts tactile-design.spec.ts delete-regression.spec.ts themes.spec.ts native-backup.spec.ts
python tools/design-gallery.py before
python tools/design-gallery.py after
$env:PHOSPHORA_AUDIT_BROWSER='firefox'
npx playwright test --config playwright.design.config.ts tactile-design.spec.ts delete-regression.spec.ts
```

Firefox проверяется отдельным движком. Эмуляция мобильного размера не измеряет
FPS, системную вибрацию и качество звука на физическом Nothing Phone 1.
