# Phosphorea 0.9.2

Сопряжение оформлено для узких экранов и светлых/тёмных тем. QR получил мягкие
модули и скруглённые маркеры при сохранении контрастного рисунка и свободного поля.
Его распознавание проверяется реальным сканером приложения.

Новые папки по умолчанию нейтральные: белые в тёмных темах, контрастные в светлых.
Зелёный доступен отдельным выбором. Существующие цвета не переписываются.

В настройках рядом с авторством появилась ссылка поддержки через DonationAlerts.
Всплывающих просьб и периодических напоминаний нет.

Синхронизация выбранных хранилищ сохраняется из 0.9.1: на пустом новом устройстве
не нужно второе нажатие; устройства с записями явно разрешают обмен.
Для синхронизации обновите приложение на обоих устройствах.
