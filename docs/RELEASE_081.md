# Phosphora 0.8.1

- Убрана рамка фокуса вокруг всего холста; фокус отдельных кнопок сохранён.
- Активные фильтры используют согласованную пару accent/onAccent, в том числе
  при наведении. «Все» в линзах переименовано в «Обычные»; ключи данных прежние.
- Иконки звука и локального сохранения имеют одинаковую геометрию. Значок
  сохранения больше не меняет форму при каждой записи камеры; ошибки видны.
- Прямой вход в оформление возвращает прямо в настройки.
- Звук мягче: атака 3.5 мс, более низкий тон и меньше высокочастотного шума.
  Контакт запускается на pointerdown, AudioContext использует interactive latency.
  Устаревший звук не проигрывается после долгого пробуждения аудиоустройства.
- Зум: один звуковой шаг на 10 единиц, не чаще одного за 160 мс. Крутилка
  сохраняет мелкие механические деления и точность управления.
- Лассо и движение получили тихие короткие звуковые зёрна с ограничением частоты;
  клавиатура, флажки, раскрывающиеся списки и кнопки поддерживают отклик.
- Новый плагин «Анимации»: вход, открытие окон и отклик папок. WAAPI анимирует
  только opacity/transform. Вход не меняет сохранённую камеру; касание отменяет
  декоративную анимацию до обработки жеста. Reduced motion учитывается.

Браузер разрешает аудио после пользовательского действия. Поэтому входной
сигнал звучит при первом касании, а не самопроизвольно при загрузке страницы.
Фактическая задержка вывода Android/Firefox зависит от аудиоустройства;
проверка фиксирует ранний вызов воспроизведения, а не аппаратную задержку.

Проверки: 252 модульных теста, svelte-check без ошибок/предупреждений, production
build; браузерные проверки Chromium и Firefox для контраста, навигации, фокуса,
иконок, раннего воспроизведения, лассо, анимаций, крутилки и отключения звука.
