# Phosphoreya 0.9.7 — ближе к пальцам

## Камера

Быстрый pinch получает короткий инерционный выход после отпускания пальцев.
Если перед отпусканием задержать пальцы, дополнительного движения нет.
Новое касание сразу перехватывает камеру. Панорамирование тоже имеет более
длинный выбег; уменьшение движения в системе отключает инерцию.

Двойной тап по крутилке показывает всю карту. Под ползунком и у кнопок ±
есть кнопка обзора. На пустом поле быстрая серия двойных тапов приближает;
после паузы больше 1,2 секунды следующий двойной тап возвращает обзор.
Почти совпадающий с максимумом последний шаг объединён с максимальным.

## Поиск и окна

На телефоне кнопка поиска ниже, в пределах большого пальца. Открытый поиск
расположен по центру по горизонтали; остальные кнопки не просвечивают под ним.
Поиск исчезает на месте перед возвращением компактной кнопки, включая ПК.
Папки и верхняя панель получили общее выравнивание.

В истории обновлений одна область прокрутки текста; действия не уезжают.
Блок автора компактный, без повторения имени и адреса Telegram.
Шрифты интерфейса используют системное семейство и доступное браузеру сглаживание.

## Плагины на устройствах

В «Устройства → Плагины и оформление» доступны три режима **получения**:

- **Плагины и настройки** — рекомендуется, прежнее поведение по умолчанию.
- **Настройки установленных** — свой набор и включение, общие параметры уже
  установленных плагинов и карты. Новые расширения автоматически не устанавливаются.
- **Свои плагины** — рабочие плагины и их настройки на этом устройстве не меняются.

Режим действует только на это устройство. Оформление принимается отдельным
переключателем. Заметки, координаты, папки и связи передаются во всех режимах.
Выбор локальных плагинов не удаляет ранее установленное и не очищает данные.
Если для заметки нужен отсутствующий пользовательский тип, его исходные данные
сохраняются; соответствующее расширение можно установить отдельно.

## Линзы и границы

Мягкая линза сохраняет приглушённое окружение во всех состояниях, включая архив
в «Обычных». Контуры папок строятся по содержимому выбранного состояния;
если оно пустое, контура нет. Сами папки остаются доступны в навигации.

При тапе по большой карте проверка связей больше не перебирает весь список
для каждой отдельной связи: используется индекс идентификаторов.
